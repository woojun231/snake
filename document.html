프로젝트 개요

기존 구글 스네이크 게임의 단조로운 플레이 경험을 개선하기 위해 두 단계에 걸쳐 신규 기능을 추가했습니다. 첫 번째 단계에서는 아이템·콤보·레벨 시스템을 도입하였고, 두 번째 단계에서는 5가지 고유 캐릭터와 각 캐릭터의 패시브·궁극기 능력을 구현하였습니다.

🎯 핵심 목표

단순 반복 플레이 → 캐릭터 선택에 따른 전략적 플레이 · 다회차 플레이 유도 · 시각적 임팩트 강화

기술 스택
HTML5 Canvas 2D API Vanilla JS (ES6+) CSS3 / Animations Web Audio API Google Fonts LocalStorage
1단계 — 아이템·콤보·레벨 시스템
🍎 7가지 아이템 시스템

사과(기본), 스피드⚡, 쉴드🛡️, 2배점✨, 슬로우❄️, 다이아💎, 폭탄💣이 랜덤으로 맵에 등장합니다. 각 아이템은 고유한 효과와 지속 시간을 가집니다.

🔥 콤보 시스템

연속으로 먹이를 먹으면 콤보가 누적됩니다. 캐릭터에 따라 최대 ×8 또는 ×12까지 증가하며 콤보 팝업 애니메이션이 표시됩니다.

📈 레벨 & XP 시스템

먹이를 먹을 때마다 XP가 쌓이며 레벨이 오를수록 게임 속도가 점점 빨라집니다. 레벨 15 이상에서는 최고 난이도가 유지됩니다.

🏆 최고 점수 저장

LocalStorage를 활용해 브라우저를 닫아도 최고 점수가 영구적으로 저장됩니다. 신기록 달성 시 골드 애니메이션이 표시됩니다.

✨ 파티클 & 효과음

아이템을 먹을 때마다 컬러 파티클이 폭발하며, Web Audio API를 활용한 아이템별 효과음이 재생됩니다.

🎨 네온 다크 디자인

Orbitron·Rajdhani 폰트, 네온 글로우, 글래스모피즘, 별자리 배경 애니메이션으로 프리미엄 게임 분위기를 구현했습니다.

2단계 — 캐릭터 선택 시스템
🎮 캐릭터 선택 화면

5개의 캐릭터 카드가 캐릭터 고유 색상 네온 테두리와 함께 표시됩니다. 선택 시 카드가 글로우 펄싱 애니메이션으로 강조됩니다.

⚡ 패시브 능력

게임 중 항상 발동되는 고유 능력입니다. 속도, 점수 배율, 벽 통과, 불꽃 흔적 등 캐릭터마다 플레이 스타일이 완전히 달라집니다.

🔮 궁극기 시스템 (Q키)

사과를 n개 먹어 게이지를 충전한 뒤 Q키로 발동합니다. 게이지 바와 Q키 버튼이 가득 찼을 때 네온 펄싱으로 알려줍니다.

🛡️ 거대화 시스템

Iron Boa 전용. 사과 10개마다 뱀이 시각적으로 1.4배 크게 펄싱하며, 10초 지속 후 원래 크기로 복귀합니다.

캐릭터 상세 설명
⚡
BLAZE VIPER
속도의 악마 · 궁극기 충전: 사과 8개
PASSIVE — 항시 발동
이동 속도 2배, 점수도 2배 항상 적용. 빠른 속도의 위험을 감수하는 대신 같은 시간에 더 많은 점수를 획득합니다.
Q — 초음속 질주
3초간 속도가 3배로 증가하며, 주변 2칸 이내의 모든 먹이와 아이템이 자동으로 흡수됩니다.
🛡️
IRON BOA
철갑의 수호자 · 궁극기 충전: 사과 12개
PASSIVE — 사과 10개마다
사과를 10개 먹을 때마다 10초간 거대화(1.4배) + 자기 몸 충돌 무적이 발동됩니다. 몸이 펄싱 애니메이션으로 커집니다.
Q — 철갑 요새
5초간 완전 무적 상태로 벽과 자기 몸 모두 통과 가능합니다. 막힌 상황에서 탈출 수단으로 활용합니다.
👻
PHANTOM SERPENT
유령의 서펜트 · 궁극기 충전: 사과 8개
PASSIVE — 항시 발동
벽에 닿으면 죽지 않고 반대편으로 이동합니다. 단, 자기 몸 충돌은 평소와 동일하게 적용됩니다.
Q — 유령 모드
4초간 자기 몸도 통과 가능해지며 뱀이 42% 반투명하게 렌더링됩니다. 어떤 충돌도 없는 완전 자유 이동 상태입니다.
🔥
INFERNO PYTHON
불꽃의 지배자 · 궁극기 충전: 사과 10개
PASSIVE — 불꽃 흔적
이동할 때마다 2틱마다 불꽃 타일이 생성됩니다 (8초 지속). 이전에 지나간 자리를 다시 밟으면 콤보 보너스 +5점을 획득합니다.
Q — 폭염 폭발
맵 전체에 불꽃이 확산되며, 5초간 주변 3칸 이내의 아이템이 즉시 자동 흡수됩니다.
💜
NEON BASILISK
콤보의 여왕 · 궁극기 충전: 사과 7개
PASSIVE — 항시 발동
점수 = 기본 점수 × 현재 콤보 배수로 계산됩니다. 또한 10초마다 콤보가 자동으로 +1 증가합니다 (최대 ×12).
Q — 콤보 폭발
현재 점수 × 콤보 × 25%가 즉시 보너스로 지급됩니다. 콤보는 유지된 채로 계속 플레이됩니다.
